# Scoring Check

## Test 1: Applied Systems — Associate Software Engineer (Strong Fit)

**Why I expected strong fit:** This was a junior/associate role requiring foundational CS knowledge, Agile familiarity, and willingness to learn — all of which match my background as a CS student with co-op experience.

**Score produced:** 75% — Good Fit

**Do I agree?** Yes, 75% feels accurate. The role explicitly targets new graduates and the core requirements match well. The system correctly identified cloud infrastructure gaps (GCP, Kubernetes) while recognizing my degree and foundational skills as strong matches.

**Did it encourage applying?** Yes — it said "Good fit, apply and highlight strengths" which is appropriate. It didn't say "don't apply" despite the gaps.

## Test 2: PHP Web Developer — Accuenergy (Stretch Fit)

**Why I expected stretch fit:** This role requires 4+ years of PHP experience and specific technologies I have limited exposure to (WordPress, WooCommerce, Apache/Linux administration).

**Score produced:** ~45-55% (Stretch)

**Do I agree?** Yes, this feels right. The system correctly identified PHP and Linux as gaps while recognizing transferable skills like JavaScript and API integrations.

**Did it encourage applying?** Yes — it suggested applying if excited about the role and gave specific advice on how to position transferable skills.

## Consistency Check

I ran Phase 3 twice on the Applied Systems posting. Both runs produced a fit score between 70-75% and gave the same "Good Fit" recommendation. The resume adaptation suggestions were slightly different in wording but covered the same core points (emphasize Agile experience, highlight cloud projects). This level of variation is acceptable since the core verdict and recommendation were consistent.
